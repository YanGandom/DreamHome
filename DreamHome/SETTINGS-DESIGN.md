# 入场、设置与关卡配置

版本：20261012-settings-1。

普通进度点击「关卡模式」会打开当前首个未完成关卡的简介。简介居中显示，半透明底板及背景模糊，下方列出三个任务和两件奖励。只有点击「开始」才载入该关卡。所有关卡都已可进入后，入口改为关卡列表；选择一关后仍需在简介中点击「开始」。

右上角齿轮在首页与游戏内均可使用。音乐和音效独立开关、默认开启，首次用户交互后播放；采用本地 Web Audio 合成轻音乐和按钮音，不需要联网下载音频。切到后台暂停声音。设置和语言保存在当前浏览器。

语言支持中文、English、Español、Français，覆盖菜单、关卡任务、奖励、成就、分类、物件／材质名称、操作按钮、提示、报错及辅助标签。`locale-data.js` 是翻译配置，`i18n.js` 负责静态和动态界面更新；切换语言不重置场景或进度。设计者自定义关卡名需填写四种语言。

在设置最下方输入代码后，点击「应用代码」或按回车，区分大小写：

- `Asi`：解锁全部道具、配色和关卡，并开放选关。不会伪造通关次数或成就统计。
- `AsiDesign`：打开关卡配置器，以后也可通过设置中的「关卡配置」按钮进入。

关卡配置器可以选择 21 关中的任意一关，修改四语名称、原场景／预置房间／空地起步、地基长宽、墙壁数量、各类家具数量、主题颜色比例，以及三个任务的类型和数量。支持新增物件、摆灯、旋转、删除窗户、沙发旋转、换地砖、全屋翻新及主题配色等任务。无原有物件的空场景不允许设置删除或翻新任务。

每关保留两件不同奖励，从既有 42 件关卡奖励中选择；新选奖励会与它原所属关卡自动交换，保证每关始终有两件、全局没有重复。原始开放的建造工具仍然开放。

保存后下次进入此关卡使用新配置。配置内容决定布局存档版本，因此旧关卡布局不会覆盖新起点；其它关卡、自定义布局及既有进度保留。

「导出关卡配置」下载 `level-presets.js`，将该文件覆盖到项目根目录并上传 GitHub，即可随 Vercel 部署发布。导出内容只有关卡设计与奖励分配，不含个人进度、代码启用状态或声音设置。仅点击保存会存到当前浏览器。

验证：游戏逻辑、表单模拟交互、配置存读、奖励唯一性、动态翻译和 Web Audio 调度均纳入自动测试。无窗口浏览器启动被环境的自动审批拒绝，尚未完成实际浏览器渲染或手机实机检查。
